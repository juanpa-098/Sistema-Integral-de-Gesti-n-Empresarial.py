# Sistema-Integral-de-Gesti-n-Empresarial.py
. Descripción del proyecto
El proyecto consiste en desarrollar un Sistema Integral de Gestión Empresarial, utilizando Python. El objetivo es crear un sistema que permita administrar diferentes procesos básicos de una empresa desde un mismo programa.
La primera versión será desarrollada como un programa de consola, utilizando un sistema de menús para acceder a las diferentes funciones. De esta manera, el proyecto será organizado por módulos y podrá crecer progresivamente a medida que adquiramos nuevos conocimientos durante la carrera.

2. Objetivo general
Desarrollar un sistema de gestión empresarial que permita organizar y administrar información relacionada con clientes, productos, inventario, proveedores, ventas, compras, empleados y finanzas, utilizando conceptos de programación y estructuras de datos.

4. Objetivos específicos
•	Crear un sistema organizado mediante diferentes módulos.
•	Implementar un menú principal para acceder a las funciones del sistema.
•	Permitir registrar, consultar, modificar y eliminar información.
•	Administrar productos e inventario.
•	Registrar clientes y proveedores.
•	Gestionar ventas y compras.
•	Llevar un control básico de empleados y movimientos financieros.
•	Generar información y reportes a partir de los datos registrados.
•	Aplicar los conocimientos adquiridos en programación y estructuras de datos.
•	Diseñar el proyecto de forma que pueda ampliarse posteriormente.
5. Funcionamiento general
El sistema contará con un menú principal desde el cual se podrá acceder a los diferentes módulos:
SISTEMA DE GESTIÓN EMPRESARIAL

2. Productos

4. Proveedores
5. Ventas
6. Compras
7. Empleados
8. Finanzas
9. Reportes
10. Administración
1. 
Cada opción tendrá su propio conjunto de funciones y operaciones, permitiendo mantener el sistema organizado y facilitar su ampliación.

Principales módulos
   
Clientes
Permitirá registrar y administrar la información de los clientes, realizar búsquedas, actualizar datos, eliminar registros y consultar información relacionada con sus operaciones.

Productos
Permitirá registrar productos con información como identificación, nombre, categoría, precio y cantidad disponible. También permitirá consultar, modificar y eliminar productos.

Inventario
Se encargará de controlar las entradas y salidas de productos, consultar existencias y detectar productos con pocas unidades o agotados.

Proveedores
Permitirá registrar y consultar información de los proveedores y relacionarlos con los productos que suministran.

Ventas
Permitirá registrar las ventas realizadas, seleccionar clientes y productos, calcular el total de la venta y actualizar automáticamente el inventario.

Compras
Permitirá registrar compras realizadas a proveedores y aumentar las cantidades disponibles en el inventario.

Empleados
Permitirá administrar información básica de los empleados, como identificación, nombre, cargo, teléfono, correo y salario.
Finanzas
Permitirá registrar ingresos y gastos y consultar el balance y los movimientos realizados.

Reportes
Permitirá obtener información general del sistema, como ventas realizadas, productos más vendidos, estado del inventario y otros datos importantes.

Administración
Será un módulo destinado a futuras funciones de administración del sistema, como usuarios, permisos y configuraciones.

7. ¿Cómo vamos a implementar el proyecto?
La implementación se realizará progresivamente en Python, comenzando por las estructuras y funciones básicas necesarias para que el sistema pueda funcionar mediante menús.
También se aplicarán los conceptos trabajados en la actividad del TAD Agenda, especialmente en el manejo de información, búsqueda, inserción, eliminación, organización de datos, pruebas y análisis de complejidad.
La clase Agenda desarrollada en la actividad se mantendrá como un ejercicio independiente según las condiciones establecidas, mientras que los conocimientos obtenidos de esta implementación se utilizarán como base para desarrollar posteriormente los módulos del SIGE.
Inicialmente se trabajará con estructuras de datos sencillas y, conforme avance el proyecto, se incorporarán nuevas funcionalidades y formas de almacenamiento.
